# PRF Administrativo — Radar + Roda Contínua

Painel público que espelha a versão montada no Work Sites. A interface reúne a roda de 33 sessões, o progresso atual e atalhos para os materiais no Notion.

- **Painel:** https://rodrigorosadantas.github.io/prf-administrativo-dashboard/
- **Fonte de verdade:** [Radar e execução no Notion](https://app.notion.com/p/3e8cf5a2673181679cd2f5532e0abf60)
- **Snapshot dos dados:** 28/09/2026

O arquivo `data.js` contém a fotografia usada pelo painel. Atualizações de progresso e materiais devem ser feitas no Notion e depois sincronizadas aqui.

O GitHub Actions publica o conteúdo estático no GitHub Pages a cada atualização da branch `main`.
